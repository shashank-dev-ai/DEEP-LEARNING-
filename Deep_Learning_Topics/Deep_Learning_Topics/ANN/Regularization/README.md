
# Regularization

## 📌 Overview

This folder contains my notes, implementations, and experiments on **Regularization**, one of the most important techniques used to improve the generalization ability of machine learning models.

The primary objective of regularization is to **reduce overfitting** by preventing the model from learning noise present in the training data.

---

## 📚 Topics Covered

- What is Regularization?
- Why Regularization is Needed
- Overfitting vs Underfitting
- Ridge Regression (L2 Regularization)
- Lasso Regression (L1 Regularization)
- Elastic Net Regularization
- Effect of Regularization Strength (Alpha / λ)
- Feature Selection using Lasso
- Bias-Variance Tradeoff
- Hyperparameter Tuning using Cross Validation

## 🚀 Key Takeaways

- Regularization helps improve model generalization.
- Ridge shrinks coefficients but does not eliminate them.
- Lasso performs feature selection by driving some coefficients to zero.
- Elastic Net combines the advantages of both Ridge and Lasso.
- The optimal regularization strength should be selected using validation techniques rather than guesswork.
